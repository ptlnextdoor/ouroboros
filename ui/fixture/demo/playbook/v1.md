# Playbook v1

- Choose t_arm from bending stress at the root under the visible load.
+ Any cantilever > 50 mm gets a gusset (thickness ~ t_arm, length ~ half the arm).
+ Assume an unlisted side load of ~0.75x the vertical load. Width >= 20 mm.
- Lightening holes only beyond 30 mm from the wall, d <= width/3.
