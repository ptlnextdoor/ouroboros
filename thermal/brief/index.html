Project brief / 17 Oct 2026

Autonomous experiments. Independent checks.

A research team that has to prove its result.

Give agents a thermal model that disagrees with measurements. Have them test explanations, revise the model and evaluate their changes on experiments reserved in advance.

One problem. A complete research loop.The proposed first build covers electronics temperature prediction. A general hardware factory and transfer to spacecraft remain future work.

Feasible scope with existing resources

Data inspected · Model improvement untested · Agent integration pending

The proposed research loop

The agent proposes the work. A separate controller owns the budget, evidence records and acceptance checks.

Planned behavior

Reproduce a baseline.

Read the dataset documentation and relevant research. Establish the measured inputs, units and assumptions. Reserve entire test experiments before fitting a simple CPU model.

Required outputResearch contract + frozen baseline

A worker saying "done" is not an acceptance condition. The final result needs a versioned model, saved observations, independent checks and a replay command.

Enough compute. A bounded build.

The first version uses a small Python model and hosted agent inference. No new GPU rental or commercial solver license is assumed.

Make the achievement inspectable.

The demo should show a research decision, the experiment it triggers and the evidence behind the final conclusion.

What success would mean

Predict reserved experiments better than a frozen baseline. Report temperature error in °C using the same data split and total budget for every method.

Compare against conventional model fitting. Preserve failed attempts. Report uncertainty or competing explanations when the measurements cannot distinguish them.

Main track: Done Means Done.
Version N+1 requires separate evidence that the research procedure improves on fresh tasks.
