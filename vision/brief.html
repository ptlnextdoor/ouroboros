The comparison (judge asked for it)

GPT-6 Astra, raw: a cylinder labeled "drone". No material, no manufacturability, no checks. Says it's done because nothing can say no.

FORGE's loop (our SQ2 supersonic quad): CNC-milled frame, carbon tubes, metal props, 3D-printed airfoil skin, real orderable parts, stress + CFD at Mach 1–2 in a dossier. Full dossier: handoff/SQ2_drone_package_for_krish.zip on the repo.

What actually runs (for the "show the codebase" beat)

goal → spec agent (Nemotron-Super) → 4 designers (Nemotron-Lightning) → CAD build → referee (gmsh + CalculiX FEA, hidden loads, no LLM) → critic (DeepSeek) → next try
after each run: playbook editor → gate (keep iff score ↑ on unseen parts) → playbook v0 → v1 → v2
verified designs → forge/distill.py → Crusoe LoRA fine-tune (job ftjob-0330cd18…, queued)

Every arrow is a file on disk. Every LLM call is logged with its dollar cost.

Numbers we can say out loud

  • Referee matches beam theory to 0.18 %.
  • A full 3-round self-improvement run cost $0.11. One verified part: about $0.001 of LLM calls.

  • Gen-1 fine-tune: 24 referee-verified designs, about $0.01 to train.
